# حضور الطلاب — فصل 7B3

صفحة عربية للتابلت والهواتف؛ يفتح الطلاب الرابط ويدخلون الرمز يدويًا أو يمسحون بطاقة QR خاصة بهم، ثم يختارون تسجيل الدخول أو الخروج. لا تحتاج إلى Google Apps Script.

## تشغيل ومشاركة التطبيق

- افتح `index.html` لتجربة التطبيق على جهاز واحد.
- للحصول على رابط يفتحه الآخرون، انشر الصفحة على خدمة صفحات ثابتة مثل GitHub Pages. بعد النشر أرسل رابط الصفحة، وليس مسار `file:///` المحلي.
- زر **رابط التطبيق** ينسخ أو يشارك عنوان الصفحة عند فتحها من رابط ويب.
- زر **بطاقات QR** ينشئ بطاقات قابلة للطباعة؛ امسح بطاقة الطالب بكاميرا الجهاز المشترك، وسيفتح التطبيق ورمزه مُدخل تلقائيًا. بعدها يضغط الطالب **تسجيل دخول** أو **تسجيل خروج**.

## حدود التخزين والخصوصية

- السجلات محفوظة في التخزين المحلي للمتصفح على الجهاز الحالي فقط. استخدموا جهازًا واحدًا مشتركًا للاحتفاظ بسجل واحد؛ لا تتزامن السجلات بين أجهزة الطلاب.
- حذف بيانات المتصفح قد يحذف السجل. نزّل CSV دوريًا للاحتفاظ بنسخة.
- لأن الصفحة تعمل دون خادم، قائمة الرموز موجودة داخل ملفات الصفحة، كما أن QR الخاص بكل طالب يحتوي رمزه داخل الرابط. استخدمها على جهاز مدرسي مُراقب، ولا تعتبر الرموز سرية.
- مسح السجل يمسح بيانات هذا الجهاز فقط. تنزيل CSV لا يتضمن الرموز.
